Welcome to my new blog! I built this site using **Astro**, **Tailwind CSS**, and **MDX**. 

### Why Astro?
- **Fast performance:** Astro ships zero client-side JavaScript by default.
- **Content Collections:** Markdown files are type-checked and organized cleanly.
- **Easy Deployment:** Deploys natively to GitHub Pages.
